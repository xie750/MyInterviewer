# UI 开发规范

## 阶段定位

当前项目已达到 `v1.0` 本地完整交付状态，后续 UI 工作以 MasterGo 原型对齐、页面体验优化和浏览器视觉验收为主。UI 阶段不重新扩大业务范围，不提前实现路线图中的未来能力。

UI 开发采用纵向切片方式：每次选择一个页面或一组强相关页面，完成原型分析、现有代码检查、接口字段映射、页面实现或调整、状态补齐、浏览器验收和进度记录。

## 设计来源

- MasterGo 原型是页面视觉依据；
- MasterGo MCP 用于读取当前选中页面或图层的结构、样式、尺寸和预览；
- MasterGo 导出的 PNG/PDF/SVG 可作为视觉验收基准；
- 现有 Vue 业务代码、路由权限和真实接口是最终实现依据；
- MasterGo 生成的结构或 D2C 代码只作为参考，不得未经整理直接替换业务源码。

当前 MasterGo MCP 已接入工具，但最近一次读取当前选中图层返回 `no online mg canvas`。后续页面开发前需要确认 MasterGo 客户端已打开目标文件、MCP 已开启，并选中页面根节点。

## 技术栈与基础规则

- 前端使用 Vue 3 + TypeScript + Vite；
- UI 组件以 Element Plus 和项目已有公共样式为基础；
- 路由守卫必须保留登录态和管理员权限拦截；
- API 调用必须复用 `frontend/src/api/` 中的封装；
- 业务类型必须复用或扩展 `frontend/src/types/index.ts`；
- 媒体、语音、姿态和虚拟人能力不可用时必须降级，不得阻断文字面试主流程；
- 不得在页面组件中写死 Mock 业务数据；确需临时 Mock 时必须集中管理，并在接入真实接口后删除。

## 视觉基础

当前工程已有基础视觉基线：

| 项目 | 当前值 |
|---|---|
| 字体 | `Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` |
| 页面背景 | `#f6f8fb` |
| 主文字 | `#1f2937` |
| 强标题 | `#111827` |
| 主色 | `#2563eb` |
| 成功/评分色 | `#0f766e` |
| 警告色 | `#b45309` |
| 边框 | `#d8dee8` |
| 卡片圆角 | `8px` |
| 常用页面宽度 | `1180px` |

后续页面调整应优先沉淀为语义化样式或可复用组件，不在单个页面中复制大量零散样式。

## 页面完成标准

页面“静态还原完成”不等于“页面完成”。每个页面至少覆盖：

- 加载中；
- 正常数据；
- 空数据；
- 请求失败；
- 无权限或未登录；
- 表单校验；
- 提交中；
- 提交成功；
- 提交失败；
- 重复提交限制；
- 浏览器控制台无新增错误；
- 1080P 下浏览器 80%、100%、125% 缩放无明显错位。

## 页面开发流程

1. 阅读 `AGENTS.md`、`docs/product/current-scope.md`、相关架构文档、当前任务和本目录 UI 文档；
2. 在 MasterGo 中选中页面根节点；
3. 使用 MasterGo MCP 读取当前选中节点结构，必要时导出截图作为视觉基准；
4. 检查现有 Vue 页面、公共样式、路由、Pinia 状态和 API 封装；
5. 在 `page-api-mapping.md` 中确认页面字段与真实接口字段；
6. 只实现当前页面范围内的 UI 和状态处理；
7. 运行必要的类型检查、构建或测试；
8. 浏览器检查功能、控制台和响应式缩放；
9. 更新 `ui-progress.md`。

## MasterGo 使用规则

- 默认只读取 MasterGo 画布，不擅自修改、删除或覆盖图层；
- 读取上下文优先使用 `get_selection_node`；
- 只有用户明确要求获取或导出前端代码时，才使用 `get_frontend_code`；
- 使用 `get_frontend_code` 前必须确认输出格式：`html`、`vue`、`react`、`wxml`、`angular`、`android` 或 `json`；
- 页面级生成或写回 MasterGo 时必须遵循 MasterGo MCP 返回的工具规则；
- 本地 Vue 业务代码不能直接由 D2C 代码覆盖；
- 修改设计稿画布前必须获得用户明确要求。

## 验收清单

- 页面视觉与 MasterGo 原型主要布局、字号、间距、圆角和层级一致；
- 页面复用现有公共样式和组件能力；
- 页面接入真实接口并处理完整状态；
- 权限边界没有弱化；
- 普通用户不能访问管理员页面或他人数据；
- 摄像头、语音、虚拟人资源失败时仍可完成文字面试；
- 文本不溢出按钮、表格、卡片或侧栏；
- 主要交互目标尺寸和间距可用；
- 动效尊重 `prefers-reduced-motion`；
- 完成后记录视觉差异和待确认问题。
