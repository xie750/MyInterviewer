# 权限设计

## 角色

| 角色 | 权限 |
|---|---|
| 普通用户 | 面试相关功能、个人记录、个人报告 |
| 管理员 | 普通用户全部功能 + 后台管理能力 |

## 权限原则

- 页面入口隐藏不能替代后端权限校验；
- 所有业务接口必须校验登录态；
- 管理员接口必须校验管理员角色；
- 用户数据必须按当前登录用户隔离；
- 查询详情时不仅校验登录，还要校验资源归属。

## MVP 权限清单

- 未登录不能访问面试页面；
- 未登录不能访问业务 API；
- 普通用户不能访问后台页面；
- 普通用户不能调用后台 API；
- 普通用户不能查看他人的面试记录；
- 管理员可以查看全站面试记录。

## 后续权限扩展

- 虚拟人素材管理只允许管理员；
- 姿态检测阈值配置只允许管理员；
- 全站姿态异常记录只允许管理员；
- 用户个人姿态报告只允许本人和管理员查看。
