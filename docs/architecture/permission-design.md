# 权限设计

## 角色

| 角色 | 权限 |
|---|---|
| 普通用户 | 岗位/风格选择、文字面试、个人记录、个人报告 |
| 管理员 | 普通用户全部功能 + 岗位管理、用户管理、全站面试记录查看 |

## 权限原则

- 页面入口隐藏不能替代后端权限校验；
- 所有业务接口必须校验登录态；
- 管理员接口必须校验管理员角色；
- 用户数据必须按当前登录用户隔离；
- 查询详情时不仅校验登录，还要校验资源归属。

## v0.1 当前实现

- `/api/auth/login` 是公开接口；
- `/api/me`、`/api/positions`、`/api/interviewer-styles` 必须登录；
- `/api/interviews/**` 必须登录，并按当前用户校验面试归属；
- 普通用户访问他人面试详情或报告返回 `404`，避免泄露资源存在性；
- `/api/admin/**` 必须是管理员；
- 管理员可以通过 `/api/admin/interviews/{id}` 只读查看任意面试详情；
- 基础用户管理只允许启停普通用户，不启停管理员账号；
- 前端路由对 `/admin` 和 `/admin/interviews/:id` 做管理员拦截，最终权限以后端为准。

## 当前测试覆盖

- 未登录访问业务接口返回 `401`；
- 普通用户访问管理员接口返回 `403`；
- 普通用户不能查看其他用户面试；
- 管理员可以查看全站面试记录；
- 管理员可以启停普通用户。

## 后续权限扩展

- 虚拟人素材管理只允许管理员；
- 姿态检测阈值配置只允许管理员；
- 全站姿态异常记录只允许管理员；
- 用户个人姿态报告只允许本人和管理员查看。
