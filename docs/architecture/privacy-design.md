# 隐私设计

## 简历数据

- 简历上传用于当前面试上下文；
- 当前实现不保存原始简历文件；
- 上传文件只在接口请求内读取并提取文本；
- 临时解析结果只保存为会话中的结构化摘要、技能、项目和提醒；
- 面试结束生成报告后清理会话中的临时解析上下文字段；
- 历史记录只保留本场是否使用过简历的布尔标识。

## 摄像头数据

- 原始视频流只在浏览器本地处理；
- 不上传、不存储原始视频帧；
- 后端只接收结构化姿态异常结果；
- 用户拒绝摄像头权限时，不阻断面试流程。

## 敏感信息

禁止在日志中输出：

- 明文密码；
- JWT；
- API Key；
- 简历全文；
- 摄像头画面；
- 大模型供应商密钥；
- 用户隐私字段。

## 权限隔离

- 普通用户只能查看自己的面试数据；
- 管理员数据访问必须经过后端角色校验；
- 导出报告时也必须校验资源归属。
