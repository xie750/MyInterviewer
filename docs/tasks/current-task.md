# 当前任务

## 任务编号

VOICE-01

## 任务名称

v0.3 语音输入与问题播报

## 项目上下文

- 当前阶段：v0.3 增量开发；
- v0.1 已完成登录、权限、岗位、面试官风格、文字面试、多轮追问、报告、历史和基础后台；
- v0.2 已完成可选简历上传、临时解析和面试上下文接入；
- 本次在不破坏文字面试闭环的前提下，增加浏览器本地语音交互能力。

## 当前行为

- 面试房间只支持文字阅读 AI 问题和手动输入回答；
- 系统尚无麦克风语音识别、识别中间态、识别失败降级或问题播报能力；
- 后端没有语音文件上传、转写或合成接口。

## 目标行为

- 用户在进行中的面试房间可以选择使用麦克风把语音转成文字回答；
- 识别结果进入原有回答输入框，用户仍可编辑后再提交；
- 用户可以开启或关闭 AI 问题自动播报，也可以手动播报最近一个 AI 问题；
- 浏览器不支持、权限拒绝、识别失败或播报失败时，页面给出明确提示并保留文字模式；
- 管理员只读面试详情不展示可操作语音输入控件；
- 不上传、不保存任何原始音频数据。

## 本次实现

- 前端新增 `services/voice.ts`，封装 Web Speech API 语音识别和浏览器语音合成；
- 面试房间新增语音控制区，包含识别支持状态、开始/停止听写、清空识别文本、自动播报开关和手动播报按钮；
- 语音识别的最终文本合并进回答框，临时文本作为实时预览；
- 提交回答、结束面试或离开页面时停止识别和播报，避免后台残留；
- 更新产品范围、路线图、AI 面试、API、隐私和版本文档。

## 本次不实现

- 不新增后端 `/api/voice/*` 接口；
- 不上传音频流、音频文件或麦克风原始数据；
- 不接入外部语音识别、语音合成供应商；
- 不做数字人口型同步、虚拟人动作或摄像头姿态检测；
- 不保存语音识别置信度、音频片段或语音日志。

## 异常降级

- 浏览器不支持语音识别：隐藏启动能力并提示继续文字输入；
- 麦克风权限拒绝：停止识别，保留文字输入；
- 识别异常或无结果：提示用户重试或手动输入；
- 语音合成不可用或被浏览器阻止：只展示文字问题；
- 页面切换、面试结束或提交中：停止正在进行的识别和播报。

## 完成标准

- 进行中面试可以通过语音识别填充回答框；
- 用户可以编辑语音识别结果并沿用原回答接口提交；
- AI 问题可自动或手动播报；
- 不支持语音能力的浏览器仍可完整完成文字面试；
- 管理员只读详情无可操作回答/语音输入；
- 前端 `npm run build` 通过；
- 后端 `mvn test` 通过，确认既有接口未回退。
