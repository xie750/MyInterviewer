# 当前任务

## 任务编号

RESUME-01

## 任务名称

v0.2 简历上传与临时解析。

## 项目上下文

- 当前阶段：v0.2 增量开发；
- v0.1 已完成登录、权限、岗位、面试官风格、文字面试、多轮追问、报告、个人历史和基础后台；
- 本次在不破坏文字面试闭环的前提下，增加可选简历上传、结构化临时解析和面试上下文接入。

## 当前行为

- 用户创建面试时只能选择岗位和面试官风格；
- AI 首问、追问和报告只使用岗位、风格和历史问答上下文；
- 系统不提供简历上传、解析或简历上下文展示。

## 目标行为

- 用户可在创建面试前可选上传简历；
- 后端解析简历为结构化摘要、技能、项目经历和提醒信息；
- 用户可以不上传简历，或在解析失败时跳过简历继续文字面试；
- 创建面试时可把解析结果作为当前面试上下文；
- 简历原文件不落库、不长期保存；解析结果只用于当前进行中的面试，面试结束后清理会话中的临时简历上下文。

## 本次实现

- 后端新增 `/api/resumes/parse` 登录后上传解析接口；
- 后端支持 `.txt`、`.md`、`.pdf`、`.docx` 简历文本提取和 10MB 大小限制；
- 后端新增简历解析 DTO、服务层和本地规则型解析实现；
- 后端扩展 `interview_session` 临时简历上下文字段，并通过新迁移演进；
- 后端扩展 `InterviewAiService`，在首问、追问和报告中使用简历摘要；
- 前端岗位选择页增加可选简历上传、解析结果预览、清除和跳过流程；
- 前端面试详情、历史和后台记录展示本场是否使用过简历；
- 更新产品范围、版本说明、接口、数据库、隐私和 AI 面试文档；
- 补充后端接口测试和前端构建验证。

## 本次不实现

- 不接入真实外部大模型供应商和 API Key；
- 不保存原始简历文件；
- 不保存简历全文到日志；
- 不实现管理员查看或下载用户简历；
- 不实现简历库、长期简历档案、批量上传或导出；
- 不实现语音识别、语音合成、摄像头姿态检测、虚拟人和素材后台。

## 异常降级

- 未上传简历：按 v0.1 文字面试流程继续；
- 简历格式不支持：提示用户并允许跳过；
- 简历为空或无法提取有效文本：提示用户并允许跳过；
- 简历解析异常：不创建持久数据，不影响岗位/风格选择和文字面试；
- 面试结束时清理临时简历上下文失败应返回明确错误，避免残留临时解析结果。

## 完成标准

- 未登录调用 `/api/resumes/parse` 返回 401；
- 支持上传文本类简历并返回结构化解析结果；
- 不支持格式、空文件或超过 10MB 文件返回明确业务错误；
- 用户可以携带简历解析结果创建面试，首问体现简历上下文；
- 用户可以不上传简历创建面试，原文字流程保持可用；
- 回答追问和报告生成可使用简历摘要；
- 面试结束后会话临时简历上下文字段被清理；
- 后端 `mvn test` 通过；
- 前端 `npm run build` 通过。
