# 当前任务

## 任务编号

ADMIN-DELIVERY-01

## 任务名称

v0.7 管理后台进阶能力与 v1.0 完整交付

## 项目上下文

- 当前稳定阶段：v0.6 虚拟人轻量状态动作已完成；
- 本次按 Harness 继续从 v0.7 推进到 v1.0 交付；
- v0.7 聚焦管理员后台进阶能力，包括虚拟人素材管理、姿态记录后台、姿态阈值配置、基础搜索筛选分页和权限回归；
- v1.0 聚焦收尾质量，包括 UI 适配、前后端回归测试、README、部署说明、演示数据和最终验收清单。

## 当前行为

- 管理员后台已有岗位管理、用户状态管理和全站面试记录只读列表；
- 姿态事件仅支持普通用户本人上报和本人/管理员在面试详情内查看；
- 姿态检测阈值固定在前端本地服务中，暂无后台配置入口；
- 虚拟人配置绑定在面试官风格字段上，暂无独立素材管理后台；
- 后台列表缺少统一搜索、筛选、分页和更完整的交付说明。

## 目标行为

- 管理员可查看全站结构化姿态记录，并按用户、面试、类型、级别搜索筛选和分页；
- 管理员可维护姿态阈值配置，并由前端面试房间尽量读取配置，失败时继续使用本地默认阈值；
- 管理员可维护虚拟人素材元数据，包括资源 key、名称、说明、图片地址、标签、强调色、启停和排序；
- 面试官风格仍可按既有字段返回虚拟人配置，同时前端素材后台能预览内置资源或外部图片地址；
- 管理后台具备更完整的分页、搜索、筛选和布局；
- README、部署说明、学习成果和最终验收清单补齐到完整交付状态。

## 本次实现

- 新增 `virtual_human_asset` 和 `posture_threshold_config` 数据表、迁移、测试数据和本地 schema；
- 新增管理员虚拟人素材管理接口；
- 新增管理员姿态事件分页查询接口；
- 新增管理员姿态阈值查询和更新接口，并新增用户侧阈值只读接口；
- 前端新增后台 API、类型和管理页面 Tab；
- 前端姿态检测服务支持从后端阈值配置初始化，失败时使用默认配置；
- 后台岗位、用户、面试记录、姿态记录和虚拟人素材增加基础搜索、筛选、分页；
- 补充后端权限/接口测试和前端构建验证；
- 更新产品范围、架构、接口、数据库、权限、隐私、路线图、版本说明、README 和最终交付文档。

## 本次不实现

- 不接入真实第三方大模型、语音识别、语音合成或数字人供应商；
- 不保存摄像头原始视频、截图、音频或动作数据；
- 不做复杂媒体文件上传、对象存储或素材 CDN 管理；
- 不做 Live2D、3D 模型、骨骼动画或真实口型同步；
- 不做正式生产级数据库分页优化和审计日志系统。

## 异常降级

- 姿态阈值接口不可用：前端继续使用本地默认阈值；
- 虚拟人素材图片不可用：前端展示默认内置虚拟人或占位状态；
- 后台筛选条件为空：按默认排序展示第一页；
- 管理员接口越权访问：后端返回 `403`；
- 普通用户访问他人姿态记录或管理接口：后端拒绝，不泄露数据。

## 完成标准

- 后端 `mvn test` 通过；
- 前端 `npm run build` 通过；
- 管理员接口均位于 `/api/admin/**` 并受管理员角色保护；
- 普通用户仍只能访问自己的面试、报告和姿态结果；
- 姿态阈值配置失败不阻断文字、语音、摄像头和虚拟人降级流程；
- README 和最终验收文档能指导本地启动、演示账号、功能验收和后续部署。
