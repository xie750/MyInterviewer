v0.1 MVP 文字模拟面试闭环收尾。

- 本次补齐面试官风格、文字面试会话、多轮追问、报告、个人历史、管理员全站记录和基础用户管理。

- 后端新增面试官风格列表接口；
- 后端新增文字面试会话创建、详情、个人历史、回答追问、结束面试、报告查询接口；
- 后端新增管理员全站面试记录和基础用户管理接口；
- 后端新增统一封装的本地规则型 `InterviewAiService`，作为 MVP 可运行 AI 降级实现；
- 前端新增面试官风格选择、面试会话、历史记录、报告页面；
- 前端扩展管理员后台，接入用户管理和全站面试记录；
- 更新产品范围、接口、数据库、权限和 AI 面试文档；
- 补充 v0.1 关键权限和面试流程测试。

## 本次不实现

- 不接入外部大模型供应商和 API Key；
- 不实现简历上传和解析；
- 不实现语音识别、语音合成；
- 不实现摄像头姿态检测；
- 不实现 2D/3D 数字人、素材后台和口型同步；
- 不实现复杂分页、搜索、批量导入、导出或正式报表系统。

## 完成标准

- 未登录访问业务接口返回 401；
- 普通用户访问管理员接口返回 403；
- 用户可以选择岗位和面试官风格创建文字面试；
- 系统可以生成首次问题并基于历史回答追问；
- 用户可以结束面试并查看评分和总结报告；
- 用户只能查看自己的面试历史、详情和报告；
- 管理员可以查看全站面试记录；
- 管理员可以查看用户列表并启停普通用户；
- 后端 `mvn test` 通过；
- 前端 `npm run build` 通过。
