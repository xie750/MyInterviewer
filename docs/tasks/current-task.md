# 当前任务

## 任务编号

AVATAR-01

## 任务名称

v0.5 虚拟人基础展示与面试官风格绑定

## 项目上下文

- 当前阶段：v0.5 增量开发；
- v0.1 已完成文字面试 MVP；
- v0.2 已完成可选简历上传与临时解析；
- v0.3 已完成浏览器本地语音听写与问题播报；
- v0.4 已完成摄像头本地轻量检测与结构化姿态事件上报；
- 本次在不改变文字、语音和摄像头检测流程的前提下，为面试官风格增加内置虚拟人基础展示。

## 当前行为

- 面试官风格只包含文字信息；
- 岗位选择页无法预览面试官形象；
- 面试房间没有当前面试官的虚拟人展示面板；
- 后端风格接口和面试详情不返回虚拟人展示配置；
- 虚拟人资源不可用时没有明确降级策略。

## 目标行为

- 每个启用的面试官风格绑定一个内置静态/轻量 2D 虚拟人形象；
- 登录用户获取风格列表时可拿到虚拟人展示配置；
- 创建面试和查询详情时可看到本场所选风格的虚拟人配置；
- 前端选择页和面试房间稳定展示虚拟人；
- 虚拟人资源缺失或加载失败时展示占位状态，不阻断文字、语音、摄像头和报告流程。

## 本次实现

- 后端新增 `interviewer_style` 虚拟人展示配置字段和 Flyway 迁移；
- 后端新增虚拟人展示 DTO，并在面试官风格响应中返回；
- 更新本地初始化数据、测试 schema 和测试数据；
- 后端测试覆盖风格列表和面试详情的虚拟人配置；
- 前端新增虚拟人资源映射服务和内置静态 SVG 资源；
- 前端岗位/风格选择页改为带虚拟人头像的风格卡片；
- 前端面试房间侧栏新增当前虚拟人展示区；
- 更新产品范围、架构、数据库、API、权限、隐私、版本和变更文档。

## 本次不实现

- 不实现数字人动作、状态动画、口型同步或语音驱动表情；
- 不实现管理员虚拟人素材上传、删除、替换和后台管理；
- 不接入第三方数字人服务；
- 不新增独立虚拟人素材表或 `/api/admin/virtual-humans` 管理接口；
- 不上传、不保存用户自定义虚拟人素材。

## 异常降级

- 后端虚拟人配置为空：前端使用默认面试官占位；
- 前端资源映射缺失：展示名称和占位图形；
- 图片资源加载失败：隐藏破损图片并显示降级占位；
- 虚拟人展示失败：不影响面试主流程和已有媒体辅助能力。

## 完成标准

- 风格列表响应包含 `virtualHuman`；
- 面试详情响应包含本场风格绑定的 `virtualHuman`；
- 选择页和面试房间可展示对应虚拟人形象；
- 虚拟人资源不可用时可降级；
- 后端 `mvn test` 通过；
- 前端 `npm run build` 通过。
