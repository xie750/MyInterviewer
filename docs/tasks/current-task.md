# 当前任务

## 任务编号

UI-TEMP-USER-FLOW-01

## 任务名称

基于 `UITemp` 本地导出稿推进用户端主流程页面还原

## 项目上下文

- 用户已将 UI 高保真导出图放入仓库 `UITemp/` 目录。
- 导出图覆盖上传简历、简历预览、岗位选择、进入面试、权限提示、面试进行中、结束面试、报告生成、面试评估报告、面试记录、暂无面试记录等用户端流程。
- 项目必须继续遵循 Harness 节奏：不提前实现未规划能力，不改后端接口契约，优先推进当前可运行、可测试的页面还原。

## 当前行为

- 前端已有登录、首页、岗位选择、面试房间、历史记录、管理员后台和无权限页。
- 用户端页面功能可用，但视觉样式与 `UITemp` 导出稿差异较大。
- 页面中部分用户可见中文文案在终端查看时呈现乱码，影响 UI 验收阅读。

## 目标行为

- 使用 `UITemp` 的本地 PNG 作为当前 UI Harness 视觉来源。
- 优先完成已有真实接口支撑的用户端页面：
  - 登录页和首页入口；
  - 上传简历、简历预览、岗位选择、面试官选择；
  - AI 面试进行中房间；
  - 面试结束后的评估报告；
  - 面试记录列表和空状态；
  - 无权限页基础提示。
- 保持现有后端接口、权限、隐私和降级策略不变。

## 本次不实现

- 不改后端接口、数据库和权限策略。
- 不实现真实 PDF 报告下载，按钮仅按设计稿占位展示。
- 不接入真实视频素材、真人头像素材、Live2D、3D 数字人或第三方数字人服务。
- 不重绘管理员后台视觉，因为 `UITemp` 当前未提供后台高保真稿。
- 不做 MasterGo 在线节点读取；本轮以 `UITemp` 本地 PNG 为准。

## 异常降级

- 简历解析失败：继续允许跳过简历进入面试。
- 语音识别或播报不可用：保留文字输入与文字问题展示。
- 摄像头不可用或权限拒绝：记录结构化不可用事件，不阻断文字面试。
- 虚拟人资源不可用：继续使用内置 SVG 或占位头像展示。

## 验收标准

- 前端生产构建 `npm run build` 通过。

- 管理员后台仍可通过 `/admin` 访问并保持基础样式承托。
