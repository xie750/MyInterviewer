# 最终验收清单

## 本地运行

- 后端可执行 `mvn spring-boot:run`；
- 前端可执行 `npm run dev`；
- 前端可通过 `VITE_API_BASE_URL=http://localhost:8080/api` 指向后端；
- 演示账号 `user / password123`、`admin / password123` 可登录。

## 普通用户流程

- 登录后进入首页；
- 选择岗位和面试官风格；
- 可选上传 `txt`、`md`、`pdf`、`docx` 简历；
- 创建面试并看到 AI 首问；
- 可文字输入回答；
- 支持语音听写和问题播报，失败时可继续文字输入；
- 可开启摄像头姿态检测，拒绝权限或不可用时不阻断面试；
- 虚拟面试官随提问、等待、倾听、思考、总结状态切换；
- 结束面试后生成报告；
- 历史记录只展示本人数据。

## 管理员流程

- 普通用户访问 `/admin` 被拒绝；
- 管理员可进入后台；
- 可管理岗位；
- 可启停普通用户，不启停管理员；
- 可查看全站面试记录和详情；
- 可筛选查看全站姿态记录；
- 可编辑姿态阈值配置；
- 可新增和编辑虚拟人素材元数据；
- 后台接口均受 `/api/admin/**` 管理员权限保护。

## 隐私与降级

- 简历原文件不保存；
- 面试结束后清理会话临时简历解析上下文；
- 摄像头原始视频流、截图不上传后端；
- 语音音频流不上传后端；
- 姿态阈值读取失败时使用前端默认值；
- 虚拟人图片加载失败时展示占位。

## 验证命令

- 后端：`mvn test`；
- 前端：`npm run build`；
- UI：重点检查 1080P 下浏览器 80%、100%、125% 缩放时后台表格、面试房间虚拟人窗口和摄像头预览窗口不遮挡核心内容。

## 当前验证结果

- 后端 `mvn test` 通过，共 27 个测试；
- 前端 `npm run build` 通过；
- 前端构建存在 Vite 体积提示和 VueUse 注释提示，不影响本次交付功能。
