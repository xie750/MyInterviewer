# 当前范围

## 当前阶段

项目已完成 v0.2 简历上传与临时解析闭环：登录、权限、岗位、面试官风格、文字面试、多轮追问、报告、个人历史、基础后台，以及可选简历上传解析和面试上下文接入。

## 已完成

- 已明确采用 Harness 方式管理长期上下文、版本增量、当前任务和验收；
- 已创建 `backend/` Spring Boot 3 + Maven 工程和 `frontend/` Vue 3 + TypeScript + Vite 工程；
- 已实现账号密码登录、JWT 签发与校验、`/api/me` 当前用户接口；
- 已实现普通用户和管理员双角色权限隔离，`/api/admin/**` 后端角色拦截；
- 已实现岗位列表、管理员岗位新增/更新/启停；
- 已实现面试官风格列表，默认包含严厉压力面、温和引导面、技术深挖面、HR 综合面；
- 已实现文字面试会话创建、首次提问、用户回答、上下文追问、结束面试和报告生成；
- 已实现登录用户简历上传与临时解析，支持 `txt`、`md`、`pdf`、`docx`；
- 已实现简历解析结果作为当前面试上下文，首问、追问和报告可结合简历摘要；
- 已实现面试结束后清理会话中的临时简历解析上下文，保留本场是否使用过简历的标识；
- 已实现普通用户个人面试历史、详情和报告查询，按当前登录用户隔离；
- 已实现管理员全站面试记录查看、只读详情查看和基础用户启停；
- 已实现前端登录页、首页、岗位/风格选择页、面试房间、历史记录页和管理员后台；
- 已补充后端业务测试，覆盖鉴权、岗位、风格、面试流程、报告、越权隔离、管理员记录和用户管理；
- 前端 `npm run build` 可通过。

## 当前真实可运行能力

- 后端可完成账号密码登录并返回 JWT；
- 后端可通过 JWT 访问当前用户、岗位、风格、面试、历史和报告接口；
- 后端可拒绝未登录业务访问、普通用户管理员越权访问、普通用户查看他人面试；
- 后端可解析简历为摘要、技能、项目经历和提醒信息，不保存原始简历文件；
- 后端可使用本地规则型 `InterviewAiService` 结合岗位、风格、历史问答和可选简历上下文生成首次问题、追问和评分报告；
- 管理员可查看全部岗位、全站面试记录、用户列表，并可启停普通用户；
- 前端可完成登录、选择岗位与面试官风格、可选上传简历、创建面试、回答、追问、结束、查看报告和历史记录；
- 前端管理员页面可管理岗位、用户状态和查看全站面试记录，并查看面试是否使用过简历；
- 当前演示账号为 `user / password123` 和 `admin / password123`。

## 当前开发原则

下一步建议进入 `v0.3`，围绕语音识别与语音输入扩展面试交互，但必须保持文字输入作为降级兜底。真实大模型接入可作为独立技术增强任务，并替换当前本地规则型 AI 服务实现。
