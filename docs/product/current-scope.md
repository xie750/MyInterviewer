# 当前范围

## 当前阶段

项目已推进到 `v1.0` 本地完整交付版。系统完成账号登录、JWT 鉴权、普通用户/管理员双角色权限、岗位选择、面试官风格、文字 AI 多轮面试、报告、历史记录、简历临时解析、浏览器本地语音辅助、浏览器本地摄像头姿态检测、虚拟人展示和轻量状态动作，以及管理员后台进阶能力。

## 已完成

- Spring Boot 3 + Maven 后端工程；
- Vue 3 + TypeScript + Vite 前端工程；
- 账号密码登录、JWT 签发与 `/api/me` 当前用户接口；
- 普通用户和管理员双角色隔离，`/api/admin/**` 后端强制管理员校验；
- 岗位列表和管理员岗位新增、更新、启停；
- 面试官风格列表，支持风格绑定虚拟人展示配置；
- 文字面试会话创建、首问、回答、追问、结束和报告生成；
- 登录用户简历上传与临时解析，支持 `txt`、`md`、`pdf`、`docx`；
- 简历解析结果作为当前面试上下文，面试结束后清理临时字段；
- 浏览器 Web Speech API 语音听写和 AI 问题播报，失败时降级到文字；
- 浏览器本地摄像头预览、轻量姿态/画面状态检测和结构化事件上报；
- 普通用户个人历史、面试详情、报告和本人姿态事件查看；
- 管理员全站面试记录查看和面试详情只读查看；
- 虚拟人内置素材展示、资源缺失占位降级和提问/等待/倾听/思考/总结/只读状态动作；
- 管理员姿态记录后台，支持事件类型、级别、面试 ID、关键词筛选和分页；
- 管理员姿态阈值配置，前端面试房间优先读取配置，失败时使用默认值；
- 管理员虚拟人素材元数据管理，支持资源 key、名称、说明、图片地址、强调色、标签、启停和排序；
- 管理后台岗位、用户、面试记录、姿态记录、阈值配置、虚拟人素材的基础搜索、筛选和分页；
- 后端 MockMvc 测试覆盖鉴权、权限、岗位、简历、面试、报告、姿态、后台用户、后台面试、后台姿态、阈值和虚拟人素材；
- 前端生产构建通过。

## 当前真实可运行能力

- 后端可使用演示账号 `user / password123` 和 `admin / password123` 登录；
- 后端可通过 JWT 访问岗位、风格、面试、报告、姿态事件和后台接口；
- 普通用户不能访问管理员后台，不能查看他人面试或姿态数据；
- 管理员可以查看全站面试、用户、姿态记录，维护岗位、姿态阈值和虚拟人素材；
- 前端可完成登录、岗位/风格选择、可选简历上传、文字/语音辅助面试、摄像头姿态辅助、追问、结束、报告和历史记录；
- 前端虚拟人可根据面试状态切换轻量动作，资源不可用时降级展示；
- 前端摄像头检测读取后端阈值配置失败时继续使用本地默认阈值；
- 摄像头原始视频流、音频流、截图和虚拟人动作数据不上传后端；
- 简历原文件不保存，面试结束后清理临时解析上下文。

## 当前开发原则

`v1.0` 已达到本地完整交付和演示状态。后续如果继续迭代，建议优先从独立增强任务推进：真实大模型供应商接入、正式姿态模型、素材上传与对象存储、生产部署自动化、OpenAPI 文档和审计日志。

## 当前 UI Harness 状态

2026-07-20 已基于 `UITemp/` 本地 PNG 导出稿完成用户端主流程第一轮页面还原：登录/首页入口、上传简历与岗位选择、面试官选择、AI 面试房间、评估报告、历史记录和空状态。后端接口、权限、隐私和降级策略保持不变。管理员后台因本轮未提供高保真稿，暂不做视觉重绘。
