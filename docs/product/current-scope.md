# 当前范围

## 当前阶段

项目已完成 Harness 文档设计和前后端基础工程搭建，尚未正式开始业务功能开发。

## 已完成

- 已明确完整任务目标；
- 已明确采用 Harness 方式管理长期上下文、版本增量、当前任务和验收；
- 已确定先做 MVP，再逐步加入简历、语音、姿态检测、虚拟人等进阶功能；
- 已创建第一版文档目录和核心项目规则。
- 已创建 `backend/` Spring Boot 3 + Maven 基础工程；
- 已创建 `frontend/` Vue 3 + TypeScript + Vite 基础工程；
- 已创建数据库、测试和验证脚本占位目录。

## 尚未完成

- 尚未创建数据库迁移脚本；
- 尚未实现登录、权限、面试、报告等业务功能；
- 尚未建立业务级自动测试和回归测试基线；
- 尚未接入大模型、语音、虚拟人和姿态检测能力。

## 当前真实可运行能力

- 后端可运行 Spring Boot 空应用；
- 后端 `mvn test` 可通过空上下文测试；
- 前端可运行 Vite 空壳应用；
- 前端 `npm run build` 可通过；
- 当前没有登录、面试、后台管理等业务功能。

## 当前开发原则

下一步应继续完善 MVP 技术设计，随后按小任务进入登录、权限和基础业务闭环开发。
