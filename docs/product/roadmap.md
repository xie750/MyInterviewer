# 版本路线图

| 版本 | 目标 | 状态 |
|---|---|---|
| `v0.1` | MVP 基础闭环：登录、JWT、双角色权限、岗位、风格、文字 AI 面试、报告、历史记录、基础后台 | 已完成 |
| `v0.2` | 简历上传与临时解析，简历只作为当前面试上下文 | 已完成 |
| `v0.3` | 语音面试辅助，浏览器本地语音听写和问题播报 | 已完成 |
| `v0.4` | 摄像头姿态检测，浏览器本地轻量检测和结构化事件上报 | 已完成 |
| `v0.5` | 虚拟人基础展示，面试官风格绑定内置静态/轻量 2D 形象 | 已完成 |
| `v0.6` | 虚拟人轻量状态动作，提问、等待、倾听、思考、总结和只读状态 | 已完成 |
| `v0.7` | 管理后台进阶能力，姿态记录、阈值配置、虚拟人素材管理、搜索筛选分页 | 已完成 |
| `v1.0` | 完整交付，测试、文档、README、部署说明、演示数据和最终验收清单 | 已完成 |

## 后续增强方向

- 接入真实大模型供应商并保留本地规则型降级；
- 接入正式语音识别/合成供应商；
- 接入正式姿态模型和更细粒度姿态评分；
- 虚拟人素材上传、对象存储和 CDN；
- OpenAPI/Swagger、审计日志、导出和批量管理；
- Docker Compose、HTTPS、生产部署和监控。

## 路线图规则

- 未来增强不影响当前 `v1.0` 本地交付状态；
- 新增能力仍应通过 Harness 变更单明确范围、降级和验收标准；
- 数据库变更继续通过新增 Flyway 迁移演进。
