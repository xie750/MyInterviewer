# 版本路线图

| 版本 | 目标 | 说明 |
|---|---|---|
| `v0.1` | MVP 基础闭环 | 登录、JWT、双角色权限、岗位、面试官风格、文字 AI 面试、报告、历史记录、基础后台 |
| `v0.2` | 简历上传与临时解析 | 简历只作为当前面试上下文，不长期保存原文件 |
| `v0.3` | 语音面试 | 已完成浏览器本地语音听写和 AI 问题播报，文字模式作为降级 |
| `v0.4` | 摄像头姿态检测 | 已完成浏览器本地轻量检测，后端只保存结构化异常结果 |
| `v0.5` | 虚拟人基础展示 | 已完成面试官风格绑定内置静态/轻量 2D 形象 |
| `v0.6` | 虚拟人动作与口型 | 增加提问、等待、思考、总结等状态动作 |
| `v0.7` | 管理后台进阶能力 | 虚拟人素材管理、姿态记录管理、阈值配置 |
| `v1.0` | 完整交付 | UI 适配、测试、文档、部署和学习成果整理 |

## 路线图规则

- 未来版本只表示计划，不代表当前任务可以提前开发。
- 每个版本都要基于上一稳定版本增量开发。
- 每个版本完成后必须更新 `current-scope.md`、相关架构文档和测试基线。
