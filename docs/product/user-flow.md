# 用户流程

## MVP 用户流程

```text
登录
-> 选择岗位
-> 选择面试官风格
-> 创建面试会话
-> AI 以文字形式发起问题
-> 用户文字回答
-> AI 根据上下文追问
-> 用户结束面试
-> 系统生成评分和总结报告
-> 用户查看个人历史记录
```

## 完整目标流程

```text
登录
-> 上传简历
-> 后端调用大模型临时解析简历
-> 选择岗位
-> 选择面试官风格
-> 加载对应虚拟人
-> 请求摄像头权限并启动姿态检测
-> AI 面试官语音/文字提问
-> 用户语音/文字回答
-> AI 追问
-> 实时记录姿态异常
-> 结束面试
-> 生成面试报告和姿态检测报告
```

## 管理员流程

```text
管理员登录
-> 进入后台
-> 管理用户、岗位、面试官风格
-> 查看全站面试记录
-> 后续管理虚拟人素材、姿态记录和检测阈值
```
