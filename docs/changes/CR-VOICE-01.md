# CR-VOICE-01 语音输入与问题播报

## 当前行为

用户在面试房间中只能阅读 AI 文字问题，并通过文本框输入回答。系统不提供麦克风听写、语音识别状态提示、问题播报或语音能力降级提示。

## 目标行为

面试房间支持浏览器本地语音交互：用户可以把口述回答识别为文字，并在提交前编辑；AI 最新问题可以自动或手动播报。所有语音能力失败时回退到现有文字面试，不影响创建面试、回答、追问、结束和报告生成。

## 新增内容

- 前端浏览器语音能力封装；
- 面试房间语音控制面板；
- 语音识别实时预览和最终文本合并；
- AI 问题自动播报开关和手动播报；
- 语音不可用、权限拒绝和识别失败提示；
- v0.3 文档、任务记录和当前范围说明。

## 修改内容

- `InterviewRoomView` 增加语音输入和播报交互；
- 前端样式增加语音控制区、识别预览和状态提示；
- 当前任务、版本范围、AI 面试、API 和隐私文档补充 v0.3 行为。

## 保持不变

- 所有回答仍通过 `POST /api/interviews/{id}/messages` 提交文字内容；
- 后端登录、权限、面试、报告、历史和管理员接口保持不变；
- 简历上传与临时解析流程保持不变；
- 管理员面试详情仍为只读查看。

## 本次不做

- 不新增后端语音识别或语音合成接口；
- 不上传、不保存原始音频流或音频文件；
- 不接入外部语音供应商；
- 不实现语音评分、口音评估、数字人口型同步或姿态检测。

## 异常降级

- 浏览器不支持 Web Speech API：页面提示语音不可用，用户继续文字输入；
- 麦克风权限拒绝或识别失败：停止听写并提示用户手动输入；
- 语音合成失败：只展示文字问题；
- 页面离开、提交回答或结束面试：主动停止识别和播报。

## 验收标准

- 支持 Web Speech API 的浏览器可把语音识别结果填入回答框；
- 临时识别文本可预览，最终识别文本可编辑后提交；
- AI 最新问题可自动播报和手动播报；
- 不支持语音能力时文字面试不受影响；
- 管理员只读视图不显示可操作语音回答控件；
- 前端构建和后端测试通过。
