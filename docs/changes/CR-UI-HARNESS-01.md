# CR-UI-HARNESS-01 UI 原型接入与页面验收 Harness 准备

## 当前行为

- 项目已完成 `v1.0` 本地交付；
- 前端已有登录、首页、岗位选择、面试房、历史记录、后台和无权限页；
- 仓库内尚未建立专门的 `docs/ui/` 页面开发规范、页面接口映射和 UI 进度表；
- MasterGo MCP 工具已在当前环境出现，但最近一次读取当前选中图层返回 `no online mg canvas`。

## 目标行为

- 建立 UI 阶段轻量 Harness 文档；
- 明确 MasterGo 原型、现有 Vue 代码和真实 API 的协作边界；
- 记录页面与接口字段映射；
- 建立页面 UI 对齐进度表；
- 为后续逐页 MasterGo 原型还原、接口联调和浏览器验收提供入口。

## 新增内容

- `docs/ui/ui-spec.md`：UI 开发规范、MasterGo 使用规则和页面完成标准；
- `docs/ui/page-api-mapping.md`：页面、路由、Vue 文件、真实接口和字段映射；
- `docs/ui/ui-progress.md`：页面业务基线、MasterGo 读取、视觉验收和推进顺序；
- 当前任务切换为 `UI-HARNESS-01`。

## 修改内容

- 更新 `docs/tasks/current-task.md`，记录本次 UI Harness 前期准备任务。

## 保持不变

- 不修改前端业务代码；
- 不修改后端接口、数据库、权限和隐私策略；
- 不改变 `v1.0` 已完成交付范围；
- 不接入新的外部模型、语音、数字人或素材服务；
- 不向 MasterGo 画布写入、覆盖或删除任何图层。

## 本次不做

- 不实现具体页面 UI 改造；
- 不导出或落盘 MasterGo 前端代码；
- 不修复具体视觉差异；
- 不创建新的公共组件；
- 不运行前后端构建测试，除非后续进入代码改造。

## 异常降级

- MasterGo MCP 不可用时，先使用导出的 PNG/PDF/SVG 和现有代码继续记录页面验收项；
- 原型字段与 API 字段不一致时，先记录差异，不自行编造字段；
- 原型资源缺失时，保持当前静态资源或占位降级策略。

## 验收标准

- `docs/ui/` 三份文档存在且能指导后续页面开发；
- 页面与接口映射覆盖当前路由和主要 API；
- UI 进度表能区分业务实现完成和 MasterGo 视觉对齐完成；
- 当前任务文档记录本次范围、结果和未完成项；
- 本次无业务代码变更。
