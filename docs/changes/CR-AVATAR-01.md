# CR-AVATAR-01 虚拟人基础展示与风格绑定

## 当前行为

面试官风格只包含名称、描述、提示词和适用场景。前端选择页和面试房间只展示文字风格信息，没有虚拟人形象，也没有资源不可用时的展示降级说明。

## 目标行为

每种启用的面试官风格绑定一个内置虚拟人展示配置。用户在选择风格、进入面试房间和查看面试详情时，可以看到对应的静态/轻量 2D 面试官形象。虚拟人资源缺失或浏览器无法加载时，页面降级为稳定占位展示，不影响文字回答、语音辅助、摄像头检测和报告生成。

## 新增内容

- `interviewer_style` 表增加虚拟人展示配置字段；
- 新增 Flyway 迁移 `V006__add_virtual_human_to_interviewer_style.sql`；
- 面试官风格响应增加 `virtualHuman` 展示对象；
- 前端新增内置虚拟人资源映射服务；
- 前端新增四个内置 SVG 虚拟人形象；
- 岗位选择页展示每种风格绑定的面试官形象；
- 面试房间侧栏展示当前虚拟人、风格状态和资源降级提示；
- v0.5 版本、任务、API、数据库、架构、权限和隐私文档。

## 修改内容

- `InterviewerStyle` 增加虚拟人配置字段；
- `InterviewerStyleResponse` 从扁平风格数据扩展为包含 `virtualHuman`；
- 本地初始化数据和测试数据为默认风格补齐虚拟人配置；
- `InterviewRoomView` 在侧栏加入虚拟人展示区，并保持摄像头姿态检测区独立可用；
- `PositionsView` 的风格选择从纯文字按钮扩展为带头像的卡片选择。

## 保持不变

- 不改变创建面试、提交回答、追问、结束和报告接口行为；
- 不改变面试官风格对 AI 提问语气的提示词作用；
- 不改变语音听写、问题播报和摄像头本地检测流程；
- 管理员后台现有岗位、用户和面试记录能力保持不变；
- 后端不保存用户上传的虚拟人素材。

## 本次不做

- 不实现 2D/3D 数字人动作、口型同步或状态动画编排；
- 不实现管理员虚拟人素材上传、启停、替换和后台管理；
- 不接入第三方数字人供应商；
- 不按用户或岗位做个性化虚拟人素材管理；
- 不新增独立 `/api/admin/virtual-humans` 管理接口。

## 异常降级

- 后端虚拟人字段为空：前端使用默认占位面试官；
- 前端资源映射缺失：展示首字母/名称占位，不阻断面试；
- 图片资源加载失败：切换为静态占位状态；
- 虚拟人展示区渲染异常：不影响文字、语音、摄像头和报告主流程。

## 验收标准

- 登录用户获取风格列表时，每个启用风格包含 `virtualHuman` 展示配置；
- 创建面试后的详情响应包含所选风格的虚拟人配置；
- 前端选择页可看到不同风格绑定的虚拟人形象；
- 前端面试房间可展示当前虚拟人，并在资源不可用时降级；
- 不新增原始媒体上传或保存；
- 后端 `mvn test` 通过；
- 前端 `npm run build` 通过。
