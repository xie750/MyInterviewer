# CR-ADMIN-DELIVERY-01 管理后台进阶能力与完整交付

## 当前行为

- 管理员后台已有岗位、用户和面试记录基础管理；
- 姿态事件只能在个人面试详情或管理员面试详情中按场次查看；
- 姿态检测阈值固定在前端；
- 虚拟人只通过面试官风格字段绑定内置资源 key；
- README、部署说明和最终验收材料仍不完整。

## 目标行为

- 管理员可以集中查看全站姿态记录，支持基础筛选、搜索和分页；
- 管理员可以配置姿态阈值，用户面试房间优先读取后端配置；
- 管理员可以维护虚拟人素材元数据，支持内置资源 key 和外部图片地址预览；
- 后台列表具备一致的搜索、筛选、分页和布局体验；
- 项目具备完整本地运行、部署、验收和演示说明。

## 新增内容

- `virtual_human_asset`：虚拟人素材元数据；
- `posture_threshold_config`：姿态阈值配置；
- `/api/admin/virtual-humans`：管理员虚拟人素材管理接口；
- `/api/admin/posture-events`：管理员姿态记录查询接口；
- `/api/admin/posture-thresholds`：管理员姿态阈值管理接口；
- `/api/posture-thresholds`：登录用户读取启用阈值配置接口；
- 前端后台虚拟人素材、姿态记录和阈值配置视图；
- 完整交付文档和验收清单。

## 修改内容

- 后台现有列表增加搜索、筛选和分页；
- 前端姿态检测初始化逻辑支持后端阈值配置降级；
- 虚拟人展示类型允许携带图片地址、标签和强调色；
- 架构、接口、数据库、权限和隐私文档更新到 v1.0。

## 保持不变

- 普通用户仍只能访问自己的面试记录、报告和姿态事件；
- 摄像头原始视频流、截图和音频不上传后端；
- 简历原文件不保存，解析上下文仍按当前面试会话临时使用；
- AI 面试仍使用当前本地规则型 `InterviewAiService`，不接第三方模型；
- 语音能力仍使用浏览器 Web Speech API 并支持文字降级。

## 本次不做

- 不做媒体文件上传、对象存储或素材 CDN；
- 不做真实数字人服务、口型同步、3D 模型或 Live2D；
- 不做正式审计日志和大规模数据分页优化；
- 不做生产域名、HTTPS 证书和容器编排实装。

## 异常降级

- 姿态阈值读取失败时，前端继续使用默认阈值；
- 虚拟人素材图片加载失败时，使用默认内置虚拟人或占位展示；
- 管理接口越权访问时后端返回 `403`；
- 管理后台筛选条件非法或为空时回到默认列表。

## 验收标准

- 后端测试通过，覆盖管理员姿态、阈值和虚拟人素材接口权限；
- 前端构建通过；
- 管理员后台能完成岗位、用户、面试、姿态、阈值、虚拟人素材的基础管理和查看；
- 用户面试主流程不因阈值接口或虚拟人资源不可用而中断；
- README、部署说明和验收清单覆盖完整交付所需信息。
