# v1.0 完整交付版本说明

## 版本目标

交付一个可本地运行、可演示、可测试的 AI 模拟面试网站完整版本，并明确外部服务未接入时的降级边界。

## 交付范围

- 普通用户：登录、岗位/风格选择、可选简历上传、文字面试、语音听写、问题播报、摄像头姿态辅助、虚拟人展示、结束面试、报告和历史记录；
- 管理员：岗位管理、用户状态管理、全站面试记录、全站姿态记录、姿态阈值配置、虚拟人素材管理；
- 权限：JWT 登录态、管理员后端权限、普通用户资源归属校验；
- 隐私：不保存简历原文件，不上传音频、视频、截图和虚拟人动作数据；
- 降级：语音、摄像头、姿态阈值、虚拟人资源不可用时不阻断文字面试主流程；
- 文档：README、当前范围、接口、数据库、权限、隐私、路线图、变更单、版本说明和当前任务文档。

## 验收命令

```powershell
cd backend
mvn test
```

```powershell
cd frontend
npm run build
```

## 已知限制

- 默认 AI 服务是本地规则型实现，未接入真实大模型；
- 语音识别和播报依赖浏览器 Web Speech API；
- 姿态检测是浏览器端轻量采样和可选 `FaceDetector`，不是正式姿态模型；
- 虚拟人素材管理当前保存元数据和图片地址，不做文件上传；
- 当前生产部署说明为本地/手动部署指导，未提供容器编排和自动化运维。
