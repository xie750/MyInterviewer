# v0.5 虚拟人基础展示版本说明

## 版本目标

在 v0.4 文字、简历、语音辅助和摄像头姿态检测闭环基础上，增加虚拟人基础展示能力，让面试官风格不只影响提问语气，也能绑定一个稳定可降级的静态/轻量 2D 形象。

## 本版本必须实现

- 面试官风格绑定内置虚拟人展示配置；
- 风格列表接口返回虚拟人名称、资源标识和描述；
- 面试详情返回本场所选风格对应的虚拟人配置；
- 前端岗位/风格选择页展示虚拟人形象；
- 前端面试房间展示当前虚拟人面板；
- 资源缺失或加载失败时降级为占位展示，不阻断面试主流程；
- 后端测试和前端构建通过。

## 本版本不实现

- 不实现数字人动作、口型同步、语音驱动表情；
- 不实现管理员虚拟人素材管理后台；
- 不接入第三方数字人服务；
- 不上传或保存用户自定义虚拟人素材；
- 不改变 AI 面试、语音和姿态检测已有接口语义。

## 权限要求

- `/api/interviewer-styles` 仍需登录；
- 普通用户只能通过既有面试详情查看自己面试绑定的虚拟人配置；
- 管理员可通过既有只读面试详情查看任意面试绑定的虚拟人配置；
- 本版本不新增管理员虚拟人素材管理权限。

## 隐私要求

- 虚拟人形象为前端内置静态资源；
- 不上传用户音频、视频、截图或虚拟人素材；
- 虚拟人展示失败只记录页面状态，不向后端上报原始媒体数据；
- 日志中不输出敏感信息。

## 验收标准

- 登录用户获取风格列表时，响应包含 `virtualHuman`；
- 创建面试和查询详情时，`style.virtualHuman` 与所选风格一致；
- 前端可在选择页和面试房间展示虚拟人；
- 虚拟人资源加载失败时显示降级占位；
- 后端 `mvn test` 通过；
- 前端 `npm run build` 通过。

## 当前完成状态

已完成 v0.5 虚拟人基础展示与面试官风格绑定。当前实现使用后端风格表内置配置和前端静态 SVG 资源映射，不新增素材上传或第三方数字人服务。

已验证：

- 后端 `mvn test` 通过，共 25 个测试；
- 前端 `npm run build` 通过；
- 前端构建存在 Element Plus/Vite 体积提示和 VueUse 纯注释提示，不影响当前功能运行。
