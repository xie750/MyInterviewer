# v0.3 语音输入与问题播报版本说明

## 版本目标

在 v0.2 可选简历上下文和文字面试闭环基础上，增加浏览器本地语音输入与 AI 问题播报，让用户可以用口述方式组织回答，同时保持文字输入作为稳定兜底。

## 本版本必须实现

- 面试房间支持麦克风语音识别；
- 识别结果转换为文字并进入原有回答框；
- 用户可以在提交前编辑识别文本；
- 支持 AI 最新问题手动播报；
- 支持 AI 问题自动播报开关；
- 浏览器不支持、权限拒绝或语音能力失败时，继续使用文字面试；
- 不上传、不保存原始音频；
- 前端构建和后端回归测试通过。

## 本版本不实现

- 后端语音识别和语音合成接口；
- 外部语音服务供应商接入；
- 音频文件上传、存储、回放或下载；
- 语音评分、发音评分和情绪识别；
- 虚拟人口型同步、姿态检测和素材后台。

## 权限要求

- 语音输入仅在用户已登录且面试仍进行中时可操作；
- 管理员只读查看面试详情时不展示语音回答控件；
- 后端业务接口权限保持 v0.2 行为。

## 隐私要求

- 麦克风音频只在浏览器本地交给浏览器语音能力处理；
- 应用不接收、不上传、不保存原始音频流或音频文件；
- 日志不记录识别全文以外的音频敏感数据；
- 用户可随时停止识别和关闭播报。

## 验收标准

- 支持 Web Speech API 的浏览器可以完成语音转文字回答；
- 用户可编辑识别文本并提交，AI 继续按既有上下文追问；
- 最新 AI 问题可播报，自动播报可开启和关闭；
- 语音不可用时页面给出提示，文字输入仍可完成完整面试；
- 前端 `npm run build` 通过；
- 后端 `mvn test` 通过。

## 当前完成状态

已完成 v0.3 语音输入与问题播报闭环。当前实现基于浏览器 Web Speech API，不上传或保存原始音频。

已验证：

- 后端 `mvn test` 通过，共 23 个测试；
- 前端 `npm run build` 通过；
- 前端构建存在 Element Plus/Vite 体积提示和 VueUse 纯注释提示，不影响当前功能运行。
