# v0.1 MVP 版本说明

## 版本目标

建立 AI 模拟面试网站的基础可运行闭环：登录、权限、岗位、面试官风格、文字 AI 面试、多轮追问、报告和基础后台。

## 本版本必须实现

- 账号密码登录；
- JWT 登录鉴权；
- 普通用户和管理员双角色权限；
- 岗位列表与岗位选择；
- 面试官风格列表与选择；
- 创建面试会话；
- 文字版 AI 首次提问；
- 用户文字回答；
- AI 根据历史对话智能追问；
- 结束面试；
- 自动生成评分和总结报告；
- 普通用户查看个人历史记录；
- 管理员查看全站面试记录；
- 基础用户管理；
- 基础岗位管理。

## 本版本不实现

- 简历上传和解析；
- 语音识别；
- 语音合成；
- 摄像头姿态检测；
- 2D/3D 数字人；
- 数字人口型同步；
- 虚拟人素材后台；
- 姿态检测记录和阈值后台。

## 保持不变

当前没有已发布业务代码。本版本建立第一个稳定基线。

## 权限要求

- 未登录用户不能访问业务页面和后端业务接口；
- 普通用户不能访问管理员接口；
- 普通用户只能查看自己的面试记录和报告；
- 管理员可以查看全站面试记录和基础管理数据。

## MVP 验收标准

- 正确账号可以登录；
- 错误密码不能登录；
- 未登录访问业务接口返回未授权；
- 普通用户访问管理员接口被拒绝；
- 用户可以完成一次文字 AI 面试；
- AI 可以根据上下文追问；
- 面试结束后可以生成评分和总结；
- 用户只能看到自己的面试历史；
- 管理员可以看到全站面试记录；
- 后端测试通过；
- 前端类型检查和构建通过。

## 当前完成状态

已完成 v0.1 MVP 基础闭环。当前 AI 能力使用后端统一封装的本地规则型实现，保证无外部 API Key 时也可完成文字面试、追问和报告生成；后续可替换为真实大模型供应商实现。

已验证：

- 后端 `mvn test` 通过；
- 前端 `npm run build` 通过。
