# v0.2 简历上传与临时解析版本说明

## 版本目标

在 v0.1 文字模拟面试闭环基础上，增加可选简历上传与临时解析能力，让系统可以结合候选人的简历摘要生成更贴近经历的首问、追问和报告建议。

## 本版本必须实现

- 登录用户上传简历并获得结构化解析结果；
- 支持常见文本简历、PDF 简历和 DOCX 简历，单文件不超过 10MB；
- 简历解析结果包含摘要、技能关键词、项目经历、教育/经验线索和提醒信息；
- 创建面试时可选携带简历解析结果；
- AI 首问、追问和报告可使用简历上下文；
- 用户未上传简历或解析失败时，继续使用 v0.1 文字面试流程；
- 原始简历文件不落库、不长期保存；
- 面试结束后清理会话中的临时简历上下文；
- 后端测试和前端构建通过。

## 本版本不实现

- 真实大模型简历解析；
- 简历库和长期简历档案；
- 管理员查看、下载或管理用户简历；
- 批量上传、导出和复杂简历评分；
- 语音、姿态检测、虚拟人和素材后台。

## 权限要求

- `/api/resumes/parse` 必须登录；
- 普通用户只能将解析结果用于自己创建的面试；
- 管理员没有新增简历管理权限；
- 所有管理员接口仍必须经过后端角色校验。

## 隐私要求

- 不保存原始简历文件；
- 不在日志中输出简历全文；
- 会话中只保留结构化解析摘要；
- 面试结束后清理临时简历上下文；
- 解析失败时不创建持久数据。

## 验收标准

- 未登录上传简历返回未授权；
- 支持格式可以成功解析；
- 不支持格式、空文件或超过 10MB 文件返回业务错误；
- 携带简历创建面试时，首问体现候选人经历上下文；
- 不携带简历创建面试时，v0.1 流程不回退；
- 面试结束后临时简历上下文被清理；
- 后端 `mvn test` 通过；
- 前端 `npm run build` 通过。
