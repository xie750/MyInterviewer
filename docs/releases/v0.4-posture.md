# v0.4 摄像头姿态检测版本说明

## 版本目标

在 v0.3 文字、简历和语音辅助面试闭环基础上，增加浏览器本地摄像头检测和结构化姿态事件上报，形成可查询的个人姿态结果基线。

## 本版本必须实现

- 面试房间支持摄像头预览；
- 浏览器本地进行轻量画面状态检测；
- 后端只接收结构化姿态事件，不接收原始视频帧；
- 用户可上报并查看自己面试的姿态事件；
- 管理员只读面试详情可看到本场姿态事件；
- 摄像头不可用时不阻断文字面试和语音辅助；
- 后端测试和前端构建通过。

## 本版本不实现

- 外部姿态模型或云端视觉识别；
- 原始视频、截图或帧数据存储；
- 管理员姿态阈值配置；
- 全站姿态事件后台列表、搜索和导出；
- 虚拟人展示、口型同步和素材后台。

## 权限要求

- `/api/posture-events` 必须登录；
- 普通用户只能给自己的进行中面试上报姿态事件；
- 普通用户只能查询自己的姿态事件；
- 管理员接口仍通过 `/api/admin/**` 做角色校验；
- 管理员可通过既有只读面试详情查看本场姿态事件。

## 隐私要求

- 摄像头原始视频流只在浏览器本地处理；
- 不上传、不保存原始视频帧、截图或视频文件；
- 后端只保存事件类型、严重级别、分数、说明和时间；
- 摄像头权限拒绝或设备不可用时，不阻断面试主流程。

## 验收标准

- 登录用户可以上报自己的姿态事件；
- 未登录上报返回 401；
- 用户越权上报或查询他人姿态事件返回 404；
- 面试详情返回姿态事件列表；
- 前端摄像头预览比例稳定，检测开关可用；
- 前端 `npm run build` 通过；
- 后端 `mvn test` 通过。

## 当前完成状态

已完成 v0.4 摄像头姿态检测与结构化结果上报闭环。当前实现为浏览器本地轻量检测：优先使用 `FaceDetector` 判断人脸位置和距离，不可用时使用亮度和画面变化兜底。

已验证：

- 后端 `mvn test` 通过，共 25 个测试；
- 前端 `npm run build` 通过；
- 前端构建存在 Element Plus/Vite 体积提示和 VueUse 纯注释提示，不影响当前功能运行。
