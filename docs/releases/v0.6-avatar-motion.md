# v0.6 虚拟人轻量状态动作版本说明

## 版本目标

在 v0.5 静态虚拟人展示基础上，让面试房间中的虚拟人随面试流程呈现轻量状态动作，包括提问、等待回答、倾听、思考、总结和只读状态。

## 本版本必须实现

- 虚拟人面板展示当前状态标签和说明；
- 问题播报时展示提问状态；
- 语音听写或回答草稿存在时展示倾听状态；
- 提交回答和结束生成报告时展示思考状态；
- 面试完成后展示总结状态；
- 未开始交互或只读详情时有稳定降级状态；
- 前端构建和后端测试通过。

## 本版本不实现

- 不做真实口型同步；
- 不做 Live2D、3D 模型、骨骼动画或视频数字人；
- 不接入第三方数字人供应商；
- 不新增管理员动作素材后台；
- 不新增后端虚拟人动作接口或动作表。

## 权限与隐私要求

- 状态动作全部在前端本地根据已有页面状态推导；
- 不上传音频、视频、截图或虚拟人动作数据；
- 不新增权限点；
- 旧后端缺少 `virtualHuman` 字段时仍使用默认虚拟人占位。

## 验收标准

- 面试房间可见虚拟人当前动作状态；
- 播报、听写、提交、结束和完成状态切换可用；
- 资源不可用时不阻断面试；
- 后端 `mvn test` 通过；
- 前端 `npm run build` 通过。

## 当前完成状态

已完成 v0.6 虚拟人轻量状态动作。当前实现全部在前端根据页面已有状态推导，不新增后端动作接口，不实现真实口型同步。

已验证：

- 后端 `mvn test` 通过，共 25 个测试；
- 前端 `npm run build` 通过；
- 前端构建存在 Element Plus/Vite 体积提示和 VueUse 纯注释提示，不影响当前功能运行。
