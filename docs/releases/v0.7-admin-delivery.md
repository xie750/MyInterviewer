# v0.7 管理后台进阶能力版本说明

## 版本目标

在 v0.6 基础上补齐管理员后台进阶能力：虚拟人素材管理、姿态记录后台、姿态阈值配置，以及基础搜索、筛选和分页。

## 本版本已实现

- 管理员全站姿态记录查询，支持关键词、面试 ID、事件类型、级别和分页；
- 管理员姿态阈值配置，支持预警阈值、严重阈值、启停、排序和说明；
- 登录用户读取启用姿态阈值，前端面试房间优先使用后端配置；
- 管理员虚拟人素材元数据管理，支持 key、名称、说明、图片地址、强调色、标签、启停和排序；
- 管理后台岗位、用户、面试、姿态、阈值、虚拟人素材统一 Tab 管理；
- 后端新增 `V007__add_admin_delivery_tables.sql`；
- 后端新增权限和接口测试。

## 本版本不实现

- 不上传或保存媒体文件本体；
- 不接入对象存储或 CDN；
- 不接入真实数字人服务；
- 不上传摄像头原始视频、截图、音频或动作数据；
- 不做大规模数据数据库分页优化。

## 验收结果

- 后端 `mvn test` 通过，共 27 个测试；
- 前端 `npm run build` 通过；
- 前端构建仍有 Vite 大包提示和 VueUse 纯注释提示，不影响当前功能运行。
