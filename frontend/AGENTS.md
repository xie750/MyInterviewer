# Frontend AGENTS.md

本目录是 AI 模拟面试网站前端工程，采用 Vue 3 + TypeScript + Vite。

## 当前阶段

当前只搭建基础工程框架，不包含登录页、面试页、后台页面或业务接口调用。

## 目录约定

- `api`：HTTP 客户端和接口模块；
- `assets`：静态资源；
- `components`：通用组件和业务组件；
- `router`：前端路由与路由守卫；
- `services`：语音、姿态检测、虚拟人等浏览器能力封装；
- `stores`：Pinia 状态管理；
- `types`：前端类型定义；
- `views`：页面级组件。

## 开发规则

- 路由权限和接口权限都要做，但最终权限必须以后端校验为准；
- 语音、摄像头、虚拟人不可用时必须降级；
- 不上传、不保存摄像头原始视频流；
- UI 开发后必须关注 1080P 下 80%、100%、125% 缩放。
